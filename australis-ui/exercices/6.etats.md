# Coder : État sélectionné

Ajouter :

```tsx
let selectedCourseId:
  number | null = null;
```

Dans le HTML :

```html
<section id="course-details"></section>
```

Puis :

```tsx
const courseDetails =
  document.querySelector(
    "#course-details"
  );

if (!courseDetails) {
  throw new Error(
    "Zone de détail introuvable"
  );
}
```

La sélection est dérivée de l’identifiant :

```tsx
function getSelectedCourse():
  Course | undefined {
  return courses.find(
    course =>
      course.id ===
      selectedCourseId
  );
}
```

Construire le rendu :

```tsx
const renderCourseDetails =
  (): void => {
    courseDetails.innerHTML = "";

    const course =
      getSelectedCourse();

    if (!course) {
      return;
    }

    const title =
      document.createElement("h2");

    title.textContent =
      course.title;

    const duration =
      document.createElement("p");

    duration.textContent =
      course.duration + " min";

    courseDetails.append(
      title,
      duration
    );
  };
```

Faire évoluer le callback du bouton d’un cours :

```tsx
button.addEventListener(
  "click",
  () => {
    selectedCourseId = course.id;
    renderCourseDetails();
  }
);
```

On réutilise ici union, `null`, `find`, `undefined` et narrowing.

# Implémenter : État dérivé et cohérence

À partir du filtre déjà fonctionnel, ajouter deux comportements :

1. afficher le nombre de cours actuellement visibles ;
2. permettre de réinitialiser le filtre avec un bouton.

Ajouter au HTML :

```html
<p id="course-count"></p>

<button
  id="reset-filter"
  type="button"
>
  Réinitialiser le filtre
</button>
```

## Contraintes

- le nombre affiché doit toujours correspondre au résultat actuel de `getVisibleCourses()` ;
- ne pas stocker ce nombre dans une nouvelle variable d’état ;
- lorsque le filtre change, la liste **et** le compteur doivent rester cohérents ;
- le bouton **Réinitialiser le filtre** doit vider à la fois l’état du filtre et le champ visible par l’utilisateur ;
- après la réinitialisation, la liste et le compteur doivent revenir à leur état initial.

## Bonus

Si un cours sélectionné disparaît à cause du filtre, décider si son détail doit rester visible ou non, puis appliquer cette décision de façon cohérente.

>💡 Le point important est de distinguer ce qui doit être **stocké** de ce qui peut être **recalculé** à partir de l’état existant.
