# Exercice 1 : Premier contrat

Écrire **sans squelette fourni** une fonction `courseLabel` qui respecte ce contrat :

```
entrée  → un titre + une durée en minutes
sortie  → "Runes anciennes — 90 min"
```

Contraintes :

- le titre est une chaîne ;
- la durée est un nombre ;
- le retour est une chaîne ;
- le type de retour doit être écrit explicitement.

Tester avec :

```
Runes anciennes / 90
Alchimie élémentaire / 120
```

Enfin, tenter volontairement d’appeler la fonction avec une durée sous forme de chaîne et observer ce que TypeScript refuse.

# Bonus 1 : Le registre des cours instables

## Situation

Le secrétariat d’Astralis reçoit parfois des données mal préparées.

On souhaite construire des fonctions simples capables de produire des libellés cohérents.

Données de départ :

```tsx
const title = "Runes anciennes";
const duration = 90;
const optionalRoom = "Tour Nord";
```

## Mission

Écrire une fonction :

```tsx
createCourseSummary(...)
```

qui puisse être utilisée ainsi :

```tsx
createCourseSummary("Runes anciennes", 90);
// "Runes anciennes — 90 min"

createCourseSummary("Alchimie élémentaire", 120, "Laboratoire");
// "Alchimie élémentaire — 120 min — Laboratoire"
```

Contraintes :

- le titre doit être une chaîne ;
- la durée doit être un nombre ;
- la salle est facultative ;
- le type de retour doit être explicite ;
- faire en sorte que TypeScript refuse un appel comme :

```tsx
createCourseSummary("Runes anciennes", "90");
```

### Extension

Une durée inférieure ou égale à zéro n’a pas de sens ici.

Faire évoluer la fonction pour qu’elle renvoie :

```
Durée invalide
```

lorsque `duration <= 0`. L’opérateur `<=` signifie « inférieur ou égal à ».
