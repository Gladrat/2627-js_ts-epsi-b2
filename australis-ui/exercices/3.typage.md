# Bonus 3 : Rendre les erreurs métier impossibles

## Situation

Le bureau des inscriptions veut représenter les règles d’accès aux cours de magie.

Partir uniquement des règles métier suivantes et **concevoir les types nécessaires**.

## Mission

Créer un modèle `CourseAccess` qui exprime les contraintes suivantes :

- `courseId` doit être `readonly` ;
- `minimumLevel` est un nombre ;
- `access` accepte uniquement :
  - `"open"`
  - `"restricted"`
  - `"forbidden"`
- `note` est facultative ;
- créer ensuite deux règles valides.

### Extension

Ajouter un type :

```tsx
StudentProfile;
```

avec :

- id readonly ;
- name ;
- level.

Puis écrire :

```tsx
canAccess(student, rule);
```

qui renvoie un booléen.

Règle simplifiée :

```
forbidden  → jamais
open       → toujours
restricted → niveau suffisant
```
