# Exercice — construire deux fonctions utiles

À partir du tableau `courses`, écrire deux fonctions.

1. `courseLabelById(id: number): string`
   - rechercher le cours correspondant ;
   - s’il existe, retourner un libellé comme :
     ```
     Alchimie élémentaire — 120 min
     ```
   - sinon retourner :
     ```
     Cours introuvable
     ```
2. `getCourseTitlesFrom(minDuration: number): string[]`
   - conserver les cours dont la durée est supérieure ou égale au seuil reçu ;
   - retourner uniquement leurs titres.

Tester au minimum :

```
courseLabelById(2)
→ "Alchimie élémentaire — 120 min"

courseLabelById(99)
→ "Cours introuvable"

getCourseTitlesFrom(100)
→ ["Alchimie élémentaire"]
```
