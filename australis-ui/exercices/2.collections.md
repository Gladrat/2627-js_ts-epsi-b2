# Exercice — construire deux fonctions utiles

À partir du tableau `courses`, écrire deux fonctions.

1. `courseLabelById(id: number): string`
   - rechercher le cours correspondant ;
   - s’il existe, retourner un libellé comme :
     ```
     Alchimie élémentaire — 120 min
     ```
   - sinon retourner :
     ```
     Cours introuvable
     ```
2. `getCourseTitlesFrom(minDuration: number): string[]`
   - conserver les cours dont la durée est supérieure ou égale au seuil reçu ;
   - retourner uniquement leurs titres.

Tester au minimum :

```ascii
courseLabelById(2)
→ "Alchimie élémentaire — 120 min"

courseLabelById(99)
→ "Cours introuvable"

getCourseTitlesFrom(100)
→ ["Alchimie élémentaire"]
```

# Bonus : Le catalogue express

## Situation

Un élève cherche uniquement les cours disponibles suffisamment longs pour valoir le déplacement.

Données autonomes :

```tsx
const courses = [
  {
    id: 1,
    title: "Runes anciennes",
    duration: 90,
    available: true,
  },
  {
    id: 2,
    title: "Alchimie élémentaire",
    duration: 120,
    available: false,
  },
  {
    id: 3,
    title: "Illusions appliquées",
    duration: 75,
    available: true,
  },
  {
    id: 4,
    title: "Enchantements défensifs",
    duration: 105,
    available: true,
  },
];
```

## Mission

Produire exactement :

```tsx
["Enchantements défensifs — 105 min", "Runes anciennes — 90 min"];
```

Règles :

- ne garder que les cours disponibles ;
- ne garder que ceux d’au moins 90 minutes ;
- transformer les objets en libellés ;
- classer le résultat du plus long au plus court ;
- **ne pas modifier le tableau `courses` d’origine**.

Le tri introduit ici une méthode supplémentaire :

```tsx
array.sort((a, b) => b.duration - a.duration);
```

`sort` trie **le tableau sur lequel il est appelé**. Dans cet exercice, on l’utilise après `filter`, car `filter` a déjà produit un nouveau tableau : le tableau `courses` d’origine reste donc intact.

Dans le filtre, `&&` signifie « et » : le cours doit être disponible **et** durer au moins 90 minutes. Pour le tri, la fonction `(a, b) => b.duration - a.duration` place les plus grandes durées avant les plus petites.
